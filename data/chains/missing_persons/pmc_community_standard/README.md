# PMC Community Standard - Enhanced Missing Child Protocol

This directory contains the source JSON and the PDF-ready HTML document for the PMC Community Standard.

## Files

- `pmc_community_standard.json` — source structured data
- `pmc_community_standard_print.html` — print-optimized HTML designed for browser **Print → Save as PDF**

## How to generate the PDF

1. Open `pmc_community_standard_print.html` in a browser.
2. Choose **Print**.
3. Select **Save as PDF**.
4. Enable **Background graphics** if your browser supports it.
5. Use standard margins or minimum margins for best pagination.

The HTML includes print CSS to reduce cutoffs and improve page breaks.
